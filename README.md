# БОГЕМА

Журнал о моде и музыке. Полноценный медиа-сайт с админкой, API и публичной витриной.

## Что это

На сайте есть лента статей с фильтрами и поиском, страница статьи с картинками и сносками, лайки, избранное, сортировки, трек дня из Яндекс Музыки и RSS. Админка позволяет создавать статьи, управлять авторами и загружать картинки. Всё работает без аккаунтов для читателей.

## Технологии

- **Backend:** FastAPI, SQLAlchemy (async), PostgreSQL, Jinja2
- **Frontend:** чистые HTML/CSS/JS (без фреймворков и сборки), marked + DOMPurify для markdown
- **Тесты:** pytest (36 тестов, SQLite in-memory)
- **Docker:** docker compose (PostgreSQL + бэкенд с раздачей фронта)

## Запуск

```bash
docker compose up --build
```

Через несколько секунд всё готово:

| Адрес | Что |
|---|---|
| http://localhost:8000/ | Публичный сайт |
| http://localhost:8000/admin | Админка (логин `admin`, пароль `admin123`) |
| http://localhost:8000/api/articles | API |
| http://localhost:8000/rss.xml | RSS-фид |

**Перед публикацией в интернете** поменяй пароль админа и секретный ключ в `docker-compose.yml`:
- `ADMIN_PASSWORD` — на надёжный пароль
- `SECRET_KEY` — на случайную строку (сгенерировать: `python -c "import secrets; print(secrets.token_urlsafe(48))"`)
- При `ENV=production` бэкенд откажется запускаться с дефолтным ключом.

## Возможности сайта

### Для читателя
- **Лента статей** — главный материал крупно сверху, остальные в сетке карточек
- **Страница статьи** — текст с буквицей, картинки в тексте, сноски, теги, время чтения
- **Лайки** — один клик, без регистрации
- **Избранное** — звёздочка на статье + отдельная страница `/favorites.html`
- **Поделиться** — Telegram, ВКонтакте или скопировать ссылку
- **Поиск по тегам** — автодополнение при вводе
- **Фильтр по автору** и **сортировка** (новые / старые / популярные)
- **Трек дня** — встроенный плеер Яндекс Музыки
- **Читайте по теме** — свежие статьи внизу страницы
- **Тёмная и светлая темы** — переключатель в шапке
- **RSS** — подписка через любой ридер

### Для редактора (админка)
- Создание и редактирование статей: Markdown-текст, обложка, картинки в тексте, сноски, теги, раздел
- Управление авторами
- Трек дня — вставка HTML-кода из «Поделиться» Яндекс Музыки
- Загрузка картинок (с проверкой типа и размера)

## Картинки в тексте статьи

В админке есть блок «Изображения в тексте»: загружаешь файл, пишешь подпись, получаешь номер (`![1]`, `![2]`…). Чтобы вставить картинку в нужное место текста, напиши маркер в статье:

```
Первый абзац…

![1]

Продолжение текста…
```

Картинки без маркера покажутся галереей в конце статьи.

## Трек дня

В админке открой «Трек дня», в Яндекс Музыке нажми «Поделиться» → «HTML код», скопируй и вставь в форму. Трек появится на главной. Бесплатно, без API-ключей.

## Разделы

Два раздела: **Мода** и **Музыка**. Список настраивается в `backend/app/core/sections.py`.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/articles` | Список статей (`?page=&per_page=&section=&tag=&sort=`) |
| GET | `/api/articles/{slug}` | Одна статья (с тегами, сносками, лайками, временем чтения) |
| GET | `/api/articles/{slug}/related` | Свежие статьи для «Читайте по теме» |
| POST | `/api/articles/{slug}/like` | Поставить лайк |
| GET | `/api/sections` | Разделы с количеством статей |
| GET | `/api/tags` | Теги с количеством статей |
| GET | `/api/settings/track` | Трек дня |
| PUT | `/api/settings/track` | Сохранить трек дня (админ) |
| GET | `/rss.xml` | RSS-фид |

Параметр `sort` принимает: `new` (новые), `old` (старые), `popular` (по лайкам).

## Тесты

```bash
cd backend
pip install -r requirements-dev.txt
pytest -v
```

36 тестов покрывают: публичные эндпоинты, лайки, валидацию, авторизацию, разделы, теги, RSS. Все выполняются за ~1 секунду на SQLite in-memory.

## CI

В `.github/workflows/ci.yml`: проверка синтаксиса Python и JS, импорт моделей, автотесты, сборка Docker-образа. Запускается на каждый push и pull request.
