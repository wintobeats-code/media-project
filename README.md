# БОГЕМА

Журнал о моде и музыке. Публичный сайт на чистых HTML/CSS/JS + админка
и API на FastAPI. Без фреймворков на фронте и без аккаунтов для читателей.

## Запуск

```bash
docker compose up --build
```

Поднимается всё: PostgreSQL, бэкенд, фронтенд. Через несколько секунд:

- **Сайт:** http://localhost:8000/
- **Админка:** http://localhost:8000/admin — логин `admin`, пароль `admin123`
- **API:** http://localhost:8000/api/articles

Пароль и логин админки меняются в `docker-compose.yml` (`ADMIN_USERNAME` /
`ADMIN_PASSWORD`). Перед публикацией обязательно задай надёжный `SECRET_KEY`.

## Что умеет сайт

**Для читателя:**
- Лента статей с главным материалом (hero) и превью текста «Читать далее»
- Страница статьи: Markdown-текст с буквицей, сносками, картинками в теле,
  тегами, временем чтения, блоком «Читайте по теме»
- **Лайки** (без регистрации — один лайк на браузер)
- **Избранное** (звёздочка на статье + страница `/favorites.html`)
- **Поделиться** в Telegram, ВКонтакте или скопировать ссылку
- **Поиск по тегам**, фильтр по автору, сортировка (новые / старые / популярные)
- **Трек дня** — встроенный плеер Яндекс Музыки
- Тёмная и светлая темы
- RSS-фид: http://localhost:8000/rss.xml

**Для редактора (админка):**
- Создание и редактирование статей: Markdown-текст, обложка, картинки в теле,
  сноски, теги, раздел
- Управление авторами
- «Трек дня» — вставляешь HTML-код из «Поделиться» Яндекс Музыки
- Загрузка картинок

## Разделы

Два раздела: **Мода** и **Музыка**. Список задаётся в
`backend/app/core/sections.py` — там же можно добавить новые.

## Картинки в тексте статьи

В админке есть блок «Изображения в тексте»: загружаешь файл, пишешь подпись,
получаешь номер (`![1]`, `![2]`…). Чтобы вставить картинку в нужное место,
просто напиши этот маркер в тексте статьи:

```
Первый абзац…

![1]

Продолжение текста…
```

Картинки без маркера покажутся галереей в конце статьи.

## Трек дня

В админке (раздел «Трек дня») вставляешь код из Яндекс Музыки:
трек → «Поделиться» → «HTML код» → копируешь и вставляешь в форму.
Трек появится на главной. Бесплатно, без API-ключей. Можно вставить и
просто ссылку на трек — она тоже распознаётся.

## Как устроено

```
backend/   FastAPI: API, админка (Jinja2), раздача статики фронта
frontend/  Публичный сайт (HTML/CSS/JS, без сборки и фреймворков)
```

Фронтенд раздаёт сам FastAPI — отдельного веб-сервера не нужно.
Путь к фронту настраивается через переменную `FRONTEND_DIR`
(в docker по умолчанию `/app/frontend`).

Markdown рендерится на фронте через `marked` + `DOMPurify` (оба файла
лежат локально в `frontend/assets/vendor/`, без CDN — это надёжнее
и защищает от XSS). Cookie-файл `access_token` читается JS для админки.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/articles` | Список статей (`?page=&per_page=&section=&tag=&sort=`) |
| GET | `/api/articles/{slug}` | Одна статья |
| GET | `/api/articles/{slug}/related` | Свежие статьи для «Читайте по теме» |
| POST | `/api/articles/{slug}/like` | Поставить лайк |
| GET | `/api/sections` | Разделы |
| GET | `/api/tags` | Теги |
| GET | `/api/settings/track` | Трек дня |
| PUT | `/api/settings/track` | Сохранить трек дня (админ) |
| GET | `/rss.xml` | RSS-фид |

`sort` принимает `new` (новые), `old` (старые), `popular` (по лайкам).

## Технологии

- **Backend:** FastAPI, SQLAlchemy (async), PostgreSQL, Alembic, Jinja2
- **Frontend:** vanilla HTML/CSS/JS, marked + DOMPurify (самохостинг)
- **Шрифты:** Oswald (логотип), Playfair Display (заголовки) — Google Fonts
- **Docker:** docker compose (PostgreSQL + бэкенд с раздачей фронта)
